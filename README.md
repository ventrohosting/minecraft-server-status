# Minecraft Server Status prüfen

Prüfe, ob ein Minecraft-Server online ist: Version, Spieler, MOTD, Server-Icon und Antwortzeit. Mit SRV-Auflösung, Port-Check und Status-Badge zum Einbetten.

**Online nutzen:** [Minecraft Server Status Checker](https://ventrohosting.com/tools/minecraft-server-status) · Demo: https://dannytheone.github.io/minecraft-server-status/

## Funktionen

- Online-Status, Version, Spieler, MOTD, Server-Icon und Antwortzeit (Java Edition)
- SRV-Auflösung (_minecraft._tcp) und Port-Check
- Status-Badge als HTML, Markdown oder BBCode zum Einbetten

## English

Minecraft server status checker: online status, version, players, MOTD, icon and latency for Java Edition servers, with SRV lookup and an embeddable status badge (HTML, Markdown, BBCode).

Use it online: https://ventrohosting.com/tools/minecraft-server-status

## Selbst hosten

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Die Abfrage nutzt die öffentliche API von ventrohosting.com.
