Minecraft Server Status prüfen

Ist der Server online? Version, Spielerzahl, MOTD, Server-Icon und Antwortzeit auf einen Blick, mit SRV-Auflösung und Port-Check. Für Server der Java Edition.

Badge und Widget

Status auf deiner Webseite zeigen

Das Badge zeigt online oder offline und die Spielerzahl und aktualisiert sich etwa alle fünf Minuten. Kopiere den Code für deine Seite, dein Forum oder deine README.

Dieses Tool gibt es auch mit Anleitung und Beispielen auf Minecraft Server Status Checker von VentroHosting, dazu weitere kostenlose Minecraft-Tools.
